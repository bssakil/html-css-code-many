Hyper Text Markup Language
HTML (HyperText Markup Language) is the standard language used to create and structure webpages.It tells the browser what to show, such as: Hadings Pragraphs Images Lnks Bttons Forms (login form, contact form, etc.)
Cascading Style Sheets
CSS (Cascading Style Sheets) is the language used to style and design webpages. While HTML builds the structure of a page, CSS controls how it looks. CSS is used for things like:Colors Font Layout (side-by-side box, grid, card layout)Backgrounds Borders Animations Spacing (margin, padding)
JavaScript (JS)
JavaScript (JS) is a programming language used to make websites dynamic, interactive, and more functional.Make buttons clickable Validate forms Create sliders, popups, menus Add animations Update content without reloading the page Build backend/server apps using Node.js
